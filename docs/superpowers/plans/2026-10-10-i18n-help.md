# Mehrsprachigkeit (DE/EN/FR) und Hilfe-Overlay – Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hilfe-Button mit Overlay und Sprachwahl (Deutsch/English/Français) einbauen und die gesamte Oberfläche übersetzen.

**Architecture:** Eigene, typisierte i18n-Schicht (`src/i18n/`: Kataloge `de/en/fr`, `createTranslate`, Plural über `Intl.PluralRules`). Die aktuelle Sprache liegt in einem kleinen zustand-Store (`src/store/localeStore.ts`, persistiert in `release-management.ui.v1`); Komponenten lesen sie über `useT()`. Das Model bleibt pur und bekommt `t` als Parameter; Store-Meldungen speichern Schlüssel statt Text und werden beim Rendern übersetzt. Das JSON-Format bleibt unverändert deutsch.

**Tech Stack:** React 19, TypeScript (strict, `erasableSyntaxOnly`), zustand, Vitest + Testing Library (jsdom), oxlint. Keine neue Laufzeit-Abhängigkeit.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-10-10-i18n-help-design.md`. **Abweichung vom Spec (bewusst vereinfacht):** statt `I18nProvider` gibt es einen externen Locale-Store mit Hooks `useLocale()`/`useT()`; `Root` setzt nur `<html lang>`. Verhalten für den Nutzer unverändert. Task 10 passt das Spec an.
- Keine neuen Laufzeit-Abhängigkeiten; Node ≥ 22.12.
- UI-Texte, Doku, Fehlermeldungen Deutsch **im Katalog `de`**; Bezeichner und Code-Kommentare Englisch.
- TypeScript strict, `erasableSyntaxOnly` (keine `enum`, Parameter-Properties, Namespaces). Kein Semikolon, einfache Anführungszeichen, 2 Leerzeichen. Kommentare nur für das *Warum*.
- Komponenten-Dateien exportieren nur Komponenten (react-refresh); Konstanten/Hilfsfunktionen in eigene `.ts`-Dateien.
- Architektur: `components` (nur Props + `useT`/`useLocale`) · `flow`/`App` → `store` → `model` → `i18n`-Kern. Das Model importiert aus `i18n` nur Typen und `createTranslate`, nie den Locale-Store.
- Standardsprache `de`, keine Erkennung der Browsersprache. Statuswerte (`offen | in Arbeit | blockiert | fertig`) und Metadaten-Schlüssel (`status`, `blockiert_grund`, `color`, `name`) bleiben deutsch (Daten, kein Schema-Eintrag, `SCHEMA_VERSION` unverändert).
- Bestehende Tests laufen unverändert in `de` (Standard ohne Provider); `src/test/setup.ts` setzt die Sprache nach jedem Test zurück.
- Neue Texte immer in **allen drei** Katalogen (`en`/`fr` sind `Catalog`-typisiert ⇒ `tsc` bricht bei fehlenden/überzähligen Schlüsseln).
- **Nicht committen oder pushen** (CLAUDE.md: nur auf ausdrückliche Anforderung). Wo die Skill-Vorlage „Commit“ vorsieht, steht hier „Diff prüfen“.

```ts
export const LOCALES = ['de', 'en', 'fr'] as const
export type Locale = (typeof LOCALES)[number]

export const DEFAULT_LOCALE: Locale = 'de'

/** Each language in its own language, so it can be found in a UI one cannot read. */
export const LOCALE_NAMES: Record<Locale, string> = {
  de: 'Deutsch',
  en: 'English',
  fr: 'Français',
}

export function parseLocale(value: unknown): Locale {
  return LOCALES.find((locale) => locale === value) ?? DEFAULT_LOCALE
}
```

`src/i18n/translate.ts`:

```ts
import { de } from './de'
import { en } from './en'
import { fr } from './fr'
import type { Locale } from './locale'
import type { Catalog, MessageKey, Params, PluralKey } from './messages'

export interface Translate {
  (key: MessageKey, params?: Params): string
  /** Picks `<key>_<form>` by the plural rules of the locale (`_other` as fallback); `{count}` is filled in. */
  plural(key: PluralKey, count: number, params?: Params): string
}

const CATALOGS: Record<Locale, Catalog> = { de, en, fr }
const PLACEHOLDER = /\{(\w+)\}/g

function format(template: string, params?: Params): string {
  if (!params) return template
  return template.replace(PLACEHOLDER, (match, name: string) =>
    Object.hasOwn(params, name) ? String(params[name]) : match,
  )
}

const cache = new Map<Locale, Translate>()

export function createTranslate(locale: Locale): Translate {
  const cached = cache.get(locale)
  if (cached) return cached

  const catalog = CATALOGS[locale]
  const rules = new Intl.PluralRules(locale)
  // The fallbacks only matter if the types were bypassed; a missing text must never blank the UI.
  const lookup = (key: MessageKey): string => catalog[key] ?? de[key] ?? key

  const translate = (key: MessageKey, params?: Params): string => format(lookup(key), params)
  const plural = (key: PluralKey, count: number, params?: Params): string => {
    const form = `${key}_${rules.select(count)}` as MessageKey
    const chosen = Object.hasOwn(catalog, form) ? form : (`${key}_other` as MessageKey)
    return format(lookup(chosen), { count, ...params })
  }

  const t: Translate = Object.assign(translate, { plural })
  cache.set(locale, t)
  return t
}
```

```ts
/** The interface language chosen last in this browser; German if none, unreadable or invalid. */
export function loadLocale(storage: Storage | null = getStorage()): Locale {
  return parseLocale(readPreferences(storage).locale ?? DEFAULT_LOCALE)
}

/** Returns false if the locale could not be written (storage missing or blocked). */
export function saveLocale(locale: Locale, storage: Storage | null = getStorage()): boolean {
  if (!storage) return false
  try {
    storage.setItem(UI_KEY, JSON.stringify({ ...readPreferences(storage), locale }))
    return true
  } catch {
    return false
  }
}
```

`src/store/localeStore.ts`:

```ts
import { create } from 'zustand'
import type { Locale } from '../i18n/locale'
import { loadLocale, saveLocale } from '../storage/uiPreferences'

interface LocaleState {
  locale: Locale
  setLocale: (locale: Locale) => void
}

/** UI state only: never recorded for undo, never exported. A failed save just means the choice is not remembered. */
export const useLocaleStore = create<LocaleState>((set) => ({
  locale: loadLocale(),
  setLocale: (locale) => {
    set({ locale })
    saveLocale(locale)
  },
}))

export const getLocale = (): Locale => useLocaleStore.getState().locale
export const setLocale = (locale: Locale): void => useLocaleStore.getState().setLocale(locale)
```

```ts
import { useEffect } from 'react'
import { useLocaleStore } from '../store/localeStore'
import type { Locale } from './locale'
import { createTranslate, type Translate } from './translate'

export function useLocale(): Locale {
  return useLocaleStore((state) => state.locale)
}

/** The translate function of the current language (stable per language, so it is safe in dependency lists). */
export function useT(): Translate {
  return createTranslate(useLocale())
}

/** Keeps `<html lang>` in line with the interface language. */
export function useDocumentLanguage(): void {
  const locale = useLocale()
  useEffect(() => {
    document.documentElement.lang = locale
  }, [locale])
}
```

`src/components/helpBody.ts`:

```ts
export const HELP_SECTIONS = [
  'start',
  'objects',
  'connect',
  'sidebar',
  'status',
  'analysis',
  'search',
  'clipboard',
  'file',
  'shortcuts',
] as const
export type HelpSection = (typeof HELP_SECTIONS)[number]

export type HelpBlock = { kind: 'paragraph'; text: string } | { kind: 'list'; items: string[] }

/** Help texts are plain lines: "- " starts a list item (consecutive ones form one list), anything else is a paragraph. */
export function parseHelpBody(body: string): HelpBlock[] {
  const blocks: HelpBlock[] = []
  for (const raw of body.split('\n')) {
    const line = raw.trim()
    if (line === '') continue
    if (line.startsWith('- ')) {
      const item = line.slice(2).trim()
      const last = blocks[blocks.length - 1]
      if (last?.kind === 'list') last.items.push(item)
      else blocks.push({ kind: 'list', items: [item] })
    } else {
      blocks.push({ kind: 'paragraph', text: line })
    }
  }
  return blocks
}
```

```tsx
import { useId } from 'react'
import type { SyntheticEvent } from 'react'
import { useT } from '../i18n/react'
import { HELP_SECTIONS, parseHelpBody } from './helpBody'
import type { HelpDialogProps } from './props'
import { useNativeDialog } from './useNativeDialog'
import './components.css'

/** The operating instructions as an overlay; the texts come from the language catalogs. */
export function HelpDialog({ open, onClose }: HelpDialogProps) {
  const dialogRef = useNativeDialog(open)
  const titleId = useId()

  function handleCancel(event: SyntheticEvent<HTMLDialogElement>) {
    event.preventDefault()
    onClose()
  }

  return (
    <dialog
      ref={dialogRef}
      className="confirm-dialog json-dialog help-dialog"
      aria-labelledby={titleId}
      onCancel={handleCancel}
    >
      {open && <HelpContent titleId={titleId} onClose={onClose} />}
    </dialog>
  )
}

// Only mounted while open, so the scroll position starts at the top every time.
function HelpContent({ titleId, onClose }: { titleId: string; onClose: () => void }) {
  const t = useT()

  return (
    <div className="confirm-dialog__content">
      <h2 className="confirm-dialog__title" id={titleId}>
        {t('help.title')}
      </h2>
      <div className="help-dialog__body">
        <p className="help-dialog__intro">{t('help.intro')}</p>
        {HELP_SECTIONS.map((section) => (
          <section key={section} className="help-dialog__section">
            <h3>{t(`help.${section}.title`)}</h3>
            {parseHelpBody(t(`help.${section}.body`)).map((block, index) =>
              block.kind === 'paragraph' ? (
                <p key={index}>{block.text}</p>
              ) : (
                <ul key={index}>
                  {block.items.map((item) => (
                    <li key={item}>{item}</li>
                  ))}
                </ul>
              ),
            )}
          </section>
        ))}
      </div>
      <div className="confirm-dialog__actions">
        <button type="button" className="ui-button" onClick={onClose}>
          {t('common.close')}
        </button>
      </div>
    </div>
  )
}
```

```ts
import { readdirSync, readFileSync } from 'node:fs'
import { join, relative } from 'node:path'
import { describe, expect, it } from 'vitest'

/**
 * Files that still contain hard-coded German UI text. Every migration task removes its files from this
 * list; the test fails for a file that is clean but still listed, so the list cannot go stale.
 */
const PENDING: readonly string[] = []

const SRC = join(process.cwd(), 'src')
const CATALOGS = new Set(['i18n/de.ts', 'i18n/en.ts', 'i18n/fr.ts'])
const GERMAN =
  /[äöüÄÖÜß]|\b(Auswählen|Verbinden|Verbindung|Zwischenablage|Schließen|Abbrechen|Hilfe|Datei|Fehler|Meldung|Wartet|wartet|Kopieren|Einfügen|Speichern|Löschen|Gruppe|Objekt|Abhängigkeit)\b/

function sourceFiles(dir: string): string[] {
  return readdirSync(dir, { withFileTypes: true }).flatMap((entry) => {
    const path = join(dir, entry.name)
    if (entry.isDirectory()) return sourceFiles(path)
    return /\.tsx?$/.test(entry.name) && !/\.test\.tsx?$/.test(entry.name) ? [path] : []
  })
}

function germanLines(file: string): string[] {
  return readFileSync(file, 'utf8')
    .split('\n')
    .map((line) => line.replace(/\/\/.*$/, ''))
    .filter((line) => !/^\s*(\/\*|\*)/.test(line))
    .filter((line) => GERMAN.test(line))
}

describe('no hard-coded German outside the catalog', () => {
  const files = sourceFiles(SRC)
    .map((file) => relative(SRC, file))
    .filter((file) => !CATALOGS.has(file))

  it.each(files.filter((file) => !PENDING.includes(file)))('%s is free of German UI text', (file) => {
    expect(germanLines(join(SRC, file))).toEqual([])
  })

  it.each(PENDING)('%s is still pending (remove it from the list once migrated)', (file) => {
    expect(germanLines(join(SRC, file)).length).toBeGreaterThan(0)
  })
})
```
